## 💼 Ключевые проекты (Коммерческий опыт)

### 📊 Бухгалтерская система (ERP)
**Роль:** Единственный аналитик и Backend-инженер (координация двух фронтенд-разработчиков)
**Стек:** Python, Django, Django REST Framework, PostgreSQL, AJAX/Bootstrap, LLM (ChatGPT/Claude)

**Задача:** Разработать с нуля систему бухгалтерского учета для автоматизации внутренних процессов компании.

**Мои ключевые решения и вклад:**
*   **Бэкенд-ядро (DRF):** Спроектировал и реализовал полный цикл учета — контракты, документы, проводки, а также генерацию многомерных отчетов.
*   **Собственный UI-движок:** Разработал архитектуру универсальных JSON-метаописаний для View. Это позволило автоматически рендерить сложные интерфейсы на стороне фронтенда без необходимости доработки кода фронта.
*   **Интеллектуальный импорт:** Создал алгоритм автоматической классификации банковских выписок на основе анализа исторических проводок.
*   **Зарплатный модуль:** Реализовал модуль на Django Templates + AJAX/Bootstrap, сохранив единую логику метаописаний для унификации отображения данных. Справился без привлечения фронтенд-разработчиков.
*   **Шаблоны загрузки CSV:** Реализовал гибкую загрузку данных в БД по шаблонам с валидацией через выделенные функции.
*   **Text-to-SQL (AI):** Внедрил формирование сложных SQL-запросов с помощью ИИ (LLM) для последующего построения отчетов.

### 📦 Проект: Regflow (Логистика / Документооборот)
**Роль:** Backend-разработчик
**Стек:** Python, Django, DRF, XML, API

**Задача:** Интеграция с внешними системами для обновления статусов электронных подписей (ЭПИ) и сертификатов сторонних организаций.

**Мои ключевые решения и вклад:**
*   **API-интеграция:** Настроил прямое взаимодействие с таможенной системой и внутренними API фирмы.
*   **Обработка данных:** Реализовал получение XML-данных, их надежный парсинг и автоматическое обновление необходимой информации в базе данных.
